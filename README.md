# Dittogen

Dittogen is an open-source brand name generation and evaluation engine.

## Structure
- `packages/core`: The pure TypeScript core for generation, filtering, scoring, and ranking.
- `apps/playground`: A static Vue-based web interface to interact with the engine.

## Development
This is a pnpm monorepo.
```bash
pnpm install
pnpm build
pnpm test
pnpm dev
```
